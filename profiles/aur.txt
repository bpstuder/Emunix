# AUR packages, built in the image chroot by build/build-image.sh. Official repos come from
# base.txt; these have no official package and are not (yet) in the [emunix] repo.
# Format: <name> <pinned AUR git commit>.
#
# Order matters: packages build top to bottom, so a dependency comes before what needs it.
# The commit is pinned so an AUR update cannot change the image silently; bump it deliberately.
# CI builds every push, so a broken PKGBUILD or dead source tarball fails the build loudly.
#
# freeimage and emulationstation-de were built here until card 14 moved them to packages/;
# the image now installs them from [emunix] (build/build-image.sh), so they are absent by
# design, not by omission.
#
# Not here, deliberately:
#   pcsx2   - AUR-only, and its own depends (kddockwidgets, rapidyaml) are AUR-only too: a
#             multi-package AUR chain that belongs in the [emunix] repo.
#   flycast - standalone is AUR-only; Dreamcast is covered by extra/libretro-flycast.
#   rpcs3   - AUR-only and large; PS3 is out of scope for M0.
#   libretro-beetle-saturn - not in any official repo; Saturn needs the [emunix] repo as well.
