# Asset & Licensing Policy

Emunix ships only software and assets we are legally allowed to redistribute.

## Rules

1. **No copyrighted ROMs, BIOS files, firmware blobs, or game assets** may be included in the
   image, the repository, or release artifacts. Users supply their own.
2. **No software whose license prohibits redistribution** (e.g. proprietary blobs without
   redistribution rights) may be bundled. Prefer open-source (GPL, MIT, Apache-2.0, BSD) or
   packages explicitly permitting redistribution.
3. Emulators and cores are included only when their upstream license permits redistribution
   in binary form. Verify before adding a new package.
4. Trademarks (console names, brand logos) must not be used in a way implying endorsement.
5. Any exception requires a written justification in the PR description and maintainer approval.

Violations are grounds for removing the offending asset and reverting the change.
